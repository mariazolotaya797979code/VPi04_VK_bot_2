# VK-бот каталога детейлинг-студии

Локальный бот сообщества ВКонтакте: каталог услуг, прайс-лист и связь с менеджером. Пользователь пишет сообществу в личные сообщения, получает кнопки под полем ввода и тексты из `catalog.py`. Это не облачный сервис: процесс Python должен работать на вашем компьютере или сервере.

Стек: **Python**, библиотека **vk_api**, **Bots Long Poll API**, настройки через **python-dotenv** (файл `.env`). Документация VK: [начало работы с ботами](https://dev.vk.com/ru/api/bots/getting-started).

---

## Возможности (как в коде)

Главное меню — постоянная клавиатура:

- **Услуги** — список услуг кнопками; по нажатию открывается карточка услуги
- **Прайс-лист** — цены по всем позициям и примечание про легковой автомобиль
- **Связаться с менеджером** — контакт из `.env` и/или приём текстового запроса в этот же чат

Карточка услуги (из `catalog.py`): цена, что входит, для кого, срок, важное примечание.

Навигация: **Назад к услугам**, **Главное меню**, **Назад**. Текстом тоже работают «начать», `/start`, приветствия, «меню», «услуги», «прайс», «менеджер» и названия услуг.

Первое сообщение новому диалогу — приветствие и меню. Дальше текст — подсказка открыть разделы кнопками.

После раздела менеджера следующее свободное сообщение считается заявкой: бот отвечает «Спасибо! Запрос передан…» и возвращает главное меню. Отдельной оплаты, онлайн-записи и календаря в коде **нет**.

## Установка и запуск

Нужен **Python 3.10+** (в `start.bat` указано 3.10+). При установке на Windows отметьте **Add python.exe to PATH**.

### Сообщество ВКонтакте

1. **Управление → Сообщения** — включите сообщения сообщества.
2. **Управление → Сообщения → Настройки для бота** — включите возможности ботов (иначе клавиатура может не пройти, ошибка 912).
3. **Управление → Дополнительно → Работа с API → Создать ключ** — право **Сообщения сообщества**. Право **Управление сообществом** нужно, если бот сам включает Long Poll и `groups.setSettings`. Иначе включите Long Poll вручную.
4. **Long Poll API**: включено, событие **Входящее сообщение** (`message_new`), версия API как в `.env` (по умолчанию **5.199**).

### Файл `.env`

В каталоге проекта:

```text
copy .env.example .env
```

Переменные (имена как в `.env.example`):

```env
VK_TOKEN=YOUR_VK_COMMUNITY_TOKEN
VK_GROUP_ID=241359266
VK_API_VERSION=5.199

STUDIO_NAME=Детейлинг-студия

MANAGER_URL=
MANAGER_ID=
```

- `VK_TOKEN` — ключ сообщества (обязательно).
- `VK_GROUP_ID` — числовой id или вид `club123456` / ссылка на сообщество. Значение в примере — образец, подставьте своё.
- `VK_API_VERSION` — версия API, по умолчанию `5.199`.
- `STUDIO_NAME` — имя в приветствии.
- `MANAGER_URL` — необязательная ссылка (например диалог менеджера).
- `MANAGER_ID` — необязательный числовой id пользователя ВК для упоминания.

Если `MANAGER_URL` и `MANAGER_ID` пустые, бот просит описать запрос в чате (марка/модель и услуга).

### Запуск на Windows

Двойной щелчок по `start.bat`: при отсутствии `.env` копируется `.env.example` и открывается Блокнот; создаётся `.venv`, ставятся зависимости, запускается `bot.py`. Окно не закрывайте. Остановка: `Ctrl+C`.

Вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python check_keys.py
python bot.py
```

Если PowerShell не даёт активировать venv: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

Python и зависимости кроссплатформенны; `start.bat` рассчитан на Windows.

### Проверка в ВК

Напишите сообществу «Начать» или приветствие. Пройдите **Услуги** → карточка → **Прайс-лист** → **Связаться с менеджером**. После контакта с менеджером короткое описание запроса должно получить подтверждение приёма.

## Условия и ограничения

- Процесс `python bot.py` должен быть запущен постоянно, иначе бот не отвечает.
- Работа зависит от API VK, ключа и настроек сообщества (сообщения, бот, Long Poll).
- Это локальный проект, не hosted SaaS и не готовый хостинг «из коробки».
- Нет оплаты, бронирования слотов и CRM: только каталог, прайс и заявка/контакт в чат.
- Клавиатура — в личных сообщениях сообщества. В беседах — текст без кнопок, ответ по упоминанию или reply.
- Если нет права «управление сообществом», Long Poll и возможности ботов включите в кабинете VK вручную.
